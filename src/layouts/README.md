# Axolotl Layout System v1.0

Import layout components from `src/layouts`. Read `docs/layout-system/usage.md` for slot APIs, responsive behavior and preview routes.

AppShell → ToolShell → archetype → tool content. Layout components do not implement tool processing. The catalog uses the same page tree in unscaled, same-origin iframe viewports. DashboardStudio and ImageConverterLayout share AppShell.
