# Design Catalog V2 — branch-specific note

Read the root `AGENTS.md` first, then `docs/catalog-v2.md`.

This branch is **a fresh catalog being assembled from approved pieces**, not a place to polish the legacy catalog or build a product. Keep migration scoped and explicit: no bulk copying of old components, no old CSS override layers, no tests, no new CI, no app backend or production functionality.

For Buttons, follow the exact four-group information architecture in `docs/catalog-v2.md`. Only one visual example per primary role; no duplicated icon variants. Preserve the approved visual style while simplifying the display.

Do not merge this branch to main or change the currently published catalog without explicit user approval.
